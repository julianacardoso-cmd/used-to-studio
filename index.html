2 · regras de ourogolden rules

Seis regras para automatizarSix rules to automate it

1

Tem BE ou GET antes? Depois vem ING.BE or GET before it? ING after it.

I'm used to drinking · I'm getting used to drinking

Aqui o to é uma preposição (como in, about, for). Depois de preposição, o verbo vai para ING.

Here to is a preposition (like in, about, for). After a preposition, the verb takes ING.

2

Sem BE e sem GET? Verbo simples.No BE and no GET? Base verb.

I used to drink coffee.

Aqui o to faz parte de used to e o verbo fica na forma base, sem ING e sem passado.

Here to belongs to used to and the verb stays in its base form: no ING, no past.

3

Used to = acabou. Só existe no passado.Used to = it ended. Past only.

I use to drink coffee now. I'm used to drinking coffee.

Para falar de hoje, não existe use to. Troque por be used to + ING.

There is no use to for the present. Switch to be used to + ING.

4

Be used to = já é normal para mim.Be used to = it's normal for me.

I'm used to waking up early. · I was used to waking up early.

Descreve um hábito que já está dentro de você. Pode ir para o passado: was / were used to.

It describes a habit that's already part of you. It can go to the past: was / were used to.

5

Get used to = o caminho até ficar normal.Get used to = the way to normal.

I'm getting used to it. · I got used to it. · You'll get used to it.

Getting é o processo agora. Got é o processo que terminou. Will get é o processo futuro.

Getting is the process now. Got is a process that finished. Will get is a future process.

6

Pergunta e negativaQuestions and negatives

used toDid you use to play? · I didn't use to play.
be used toAre you used to playing? · I'm not used to playing.
get used toAre you getting used to playing? · I can't get used to playing.

Com did / didn't o passado já está no auxiliar, então use perde o D.

With did / didn't the past is already in the auxiliary, so use loses the D.

Teste do IT (pega-erro rápido)The IT test (quick error catcher)

Dá para colocar it depois de used to? Se der, o to é preposição e o verbo precisa de ING.

Can you put it after used to? If you can, to is a preposition and the verb needs ING.

I'm used to it ✓ → I'm used to drinkingI used to it ✗ → I used to drink

Seus erros mais comunsYour most common mistakes

I am used to drink coffee.I am used to drinking coffee.
I used to being shy.I used to be shy.
Did you used to play golf?Did you use to play golf?
He's getting used to eat late.He's getting used to eating late.

Como soa (inglês americano)How it sounds (American English)

used to costuma soar como "iúst-tâ", com o to fraco (/tə/). Em didn't use to, o som final é "iuss-tâ". Em be used to, o to também é fraco, e o ING fecha rápido: drink-ing.

used to usually sounds like "yoost-tuh" with a weak to (/tə/). In didn't use to the ending sounds like "yoos-tuh". In be used to the to is also weak and the ING closes quickly: drink-ing.

The line shows where the voice goes up and down in American English. Big coral dots are stressed syllables. Dashed dots are weak (reduced) syllables.
